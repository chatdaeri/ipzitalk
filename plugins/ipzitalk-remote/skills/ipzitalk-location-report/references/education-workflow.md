# 교육 환경 워크플로우 (공유 부품)

> 이 파일이 정본이다. 스킬 폴더 밖 경로에 의존하지 않는다(standalone).
> 원본 단독 스킬: `ipzitalk-education-environment` (초안 v0.3). center 전제(좌표 공유).
> **최종 갱신 2026-07-09** — 반경 규칙 R1~R3 · `subcategory_filter` 후처리 gotcha · 광역/개수형 축 격리 반영.

## 반경 처리 (R1~R3)
| 층위 | 값 | 사용자 `radius_m` |
|---|---|---|
| **밴드**(등급 판정) | 축별 절대 거리, 불변 | 영향 없음 |
| **표시 반경**(지도 원·목록) | 초등·중·고 기본 1,000 | 그대로 반영 |
| **수집 반경**(API 호출) | `max(radius_m, 밴드최대 1000 × 1.25)` | 하한만 보장 |

- **R2가 없으면 오판한다.** 사용자가 300m를 줘도 1,250m까지 탐색해야 800m 학교를 놓치고 ">1000 미흡"으로 잘못 판정하지 않는다. **"반경 내 없음"과 "이격"은 다르다.**
- **cap 5,000m.** 지방 사업지는 1km 안에 초등학교가 없을 수 있어 2~3km까지 봐야 한다. 5km 안에도 0건이면 "5km 내 초등학교 없음(미확인)"으로 명시하고 멈춘다. 추정 금지.
- **광역 축 격리**: **대학은 3,000m 고정**, `radius_m` 미적용.
- **개수형 축 고정**: **학원 판정창 700m 고정.** 반경을 바꾸면 "≥20 밀집" 밴드가 무의미해진다. 사용자가 학원 반경을 지정하면 **개수만 제시하고 등급은 유보**한다.

## 검색 단계 (center = 사업지 좌표)
1. **초등학교**(근린) — `search_by_nearby_category(center, radius_m=max(radius_m,1250), categories=['school_elementary'])` → 최근접(초품아 밴드).
2. **중학교 / 고등학교**(근린) — `search_by_nearby_category(center, radius_m=max(radius_m,1250), categories=['school'], subcategory_filter={category_name_contains:"중학교"})` (및 `"고등학교"`).
3. **대학교**(광역, 고정 3,000m) — `search_by_nearby_category(center, radius_m=3000, categories=['school'], subcategory_filter={category_name_contains:"대학교"})` → 존재 여부·최근접.
4. **학원**(개수형, 판정창 700m 고정) — `search_by_nearby_keyword(center, radius_m=700, query="학원", grid=true, category_filter={include_contains:["학원"]})`
   → **700m 내 개수(밀집)** + 최근접. `grid=true`가 45건 캡을 우회한다(`truncated:false` 확인).

## 🚨 45건 캡 + `subcategory_filter`는 후처리다 (실측)
`search_by_nearby_category`는 45건 상한이고 **`grid` 옵션이 없다.** 더 나쁜 것은 **`subcategory_filter`가 서버 필터가 아니라 45건을 받은 뒤 거르는 후처리**라는 점이다.

방배 r3000 실측:
```
중학교 13 + 고등학교 13 + 대학교 3 + 초등학교 16 = 45   ← 카카오 상한 정확히 도달
```
`categories:['school']` 원본이 45건에서 잘렸고, 3km 내 중·고·대학 일부는 응답에 **아예 오지 않았다**. 네 축 모두 `truncated:true`.

- 다만 `sort=distance`라 **최근접은 항상 정확** → **등급 판정은 안전, 목록·개수는 근사.**
- **서울 학교 밀집지는 반경 2km부터 이미 캡에 걸린다.** cap 5km는 판정용이지 목록용이 아니다.

## 🚨 운영 중이 아닌 학교를 걸러낸다 (실측 2026-07-10)

카카오는 학교의 운영 상태를 **장소명 문자열에만** 적는다. `category_name` 은 정상 학교와 동일하고
거리도 정상으로 준다. **카테고리 검색도 걸러주지 않는다.**

```
서울반포초등학교 (휴교)          728m   교육,학문 > 학교 > 초등학교
반포중학교 (휴교)               626m   교육,학문 > 학교 > 중학교
산빛초등학교 (2027년 3월 예정)    311m   교육,학문 > 학교 > 초등학교
```

서울반포초 바로 앞(반경 700m) 실측 — 그대로 쓰면 **문 닫은 학교로 최우수 등급**이 난다:
```
서울반포초등학교 (휴교)   17m    ← 🟢 초품아 인접으로 오판
계성초등학교            520m    ← 운영 중 최근접. 올바른 등급은 🟡
```

- 장소명에 `예정`·`개교`·`(20NN년`·`휴교`·`폐교` 가 있으면 **개수·등급·최근접에서 뺀다.**
  목록·지도에는 상태 꼬리표를 달아 참고로만 남긴다.
- 재건축 이주 구역(반포·둔촌 등)에 잦다. 휴교는 재개교할 수도, 안 할 수도 있다.
  **재개교 시점을 추정하지 말 것.** 장소명에 있는 문자열만 화면에 쓴다.
- 키워드 검색은 `학교부속시설`(교무실·운동장·정문·별관)까지 딸려 온다.
  실측 `초등학교` 15건 중 8건이 부속시설이었다. `category_name` 이 `> 학교 >` 로 이어지는 것만 학교로 센다.

## 밴드 (직선거리 / 학원은 개수)
| 축 | 기준 |
|---|---|
| 초등(초품아) | ≤300 우수 / 300–500 양호 / 500–1000 보통 / >1000 미흡 |
| 중·고 | 최근접 ≤500 우수 / 500–1000 양호 / >1000 미흡 |
| 대학 | 2~3km 내 존재 = 있음 / 없음 / **확인 불가**(아래 0건 재확인 절차) |
| 학원(학세권) | **700m 고정창** 개수 ≥20 밀집 / 8–19 다수 / 1–7 소수 / 0 없음 |

## 0건이 나오면 재확인한다 (🚨 부재 단정 금지)
카테고리 검색은 **45건 캡이 서버가 아니라 후처리 필터**라, 밀집지역에서는 실제로 있는 시설이 0건으로 보일 수 있다.
어떤 축이든 **0건이 나오면 그대로 "없음"이라 쓰지 말고 아래를 수행한다.**

1. `metadata.truncated` 를 본다. `true` 면 캡에 걸린 것이므로 **부재로 단정하지 않는다.**
2. 같은 축을 **키워드 검색으로 한 번 더** 조회한다(카테고리 필터 대신 `search_by_nearby_keyword`, 예: 대학 → `"대학교"`). 반경은 그 축의 판정창 그대로.
3. 두 방식 모두 0건이고 `truncated:false` 면 → **"반경 내 없음"** 으로 확정한다.
4. 한쪽이라도 캡에 걸렸거나 결과가 엇갈리면 → **"확인 불가(검색 한계)"** 로 적는다. `없음`과 `확인 불가`를 섞어 쓰지 않는다.
5. 재확인에도 좌표·center는 재해소하지 않는다(크레딧 낭비).

## 종합 등급
- 초등 접근성 + 학원 밀집을 주 축, 중·고·대학 보조. ★★★/★★☆/★☆☆ + 한줄평(학군 특성 정직).
- **초등 최근접이 타 자치구 소재면 반드시 배정주의 명시.**
- **초등 배정 확인 링크 필수**: 학구도 안내 https://schoolzone.emac.kr/gis/gis.do

## Gotcha (실측)
- ⚠️ **최근접 초등학교가 타 자치구일 수 있다.** 방배 → 동작구 남사초 425m(서초구 배정 후보는 이수초 545m). 배정 미확인 + 학구도 링크 필수.
- ⚠️ **학원 개수는 계열 무관 총계다.** 방배 700m 59개 중 교과(국·영·수·논술·보습·어학) 약 22 · 예체능 약 30 · 기타(컴퓨터·간호·운전면허·카이로프랙틱) 약 7. "학원 밀집 = 교과 학원가"로 읽으면 과대평가된다 → hedge에 명시.
- ⚠️ 학원 원본 180건 → 중복제거 59개. `total_found`가 아니라 dedupe 후 개수를 쓴다.

## 지도 호출 규칙
- `center` + `radius_m` 항상 함께, 마커 2개 이상.
- 🚨 **반경 눈금 마커를 넣지 않는다.** 예전엔 `fitBounds`가 반경 원을 무시해 원이 잘리는 걸 막으려고
  정북·남·동·서에 회색 더미 마커 4개를 심었다. 사용자에게는 **정체를 알 수 없는 점**으로 보여 혼란만 준다.
  **원이 잘리더라도 마커는 실제 장소만 찍는다.** (근본 해결은 `render.ts`가 원을 bounds에 포함하도록 고치는 것 — 발견사항 6번)
- 카드 CSS: `.map{overflow-x:auto}` + `.map iframe{min-width:720px}`.

## hedge (필수 승계)
- 직선거리 기준 · **배정/학군 미확인**(타 자치구면 배정주의) · **학원 개수는 계열 무관 총계**(과목·규모 미구분) · 중·고·대학 목록은 45건 캡으로 불완전 가능 · 출처(카카오 로컬)·조회일.
- 금지: "초품아 확정", "배정 학교 = OO", "명문 학군" 단정.

## 엣지
- 특정 축 0건 → "없음/원거리" 명시, 거리 지어내지 않음.
- 표시 반경엔 없고 수집 반경 안에 있으면 → 회색 + "요청 반경 밖 · N km" 꼬리표(R3).
